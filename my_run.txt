UltraFedFM 项目运行说明（Ubuntu）

1. 项目用途
本项目是一个超声影像基础模型项目，整体流程分成两段：
(1) 联邦预训练：在多客户端超声数据上训练 UltraFedFM
(2) 下游任务微调/评估：把预训练权重用于分类诊断、二分类分割、多类分割

项目主入口：
- 联邦预训练：main_pretrain.py
- 分类诊断：main_diagnosis.py
- 二分类分割：main_binary_segmentation.py
- 多类分割：main_multi_segmentation.py

脚本入口：
- 预训练：scripts/pretrain.sh
- 分类训练：scripts/diagnosis.sh
- 分类评估：scripts/eval_diagnosis.sh
- 二分类分割训练：scripts/binary_segmentation.sh
- 二分类分割评估：scripts/eval_binary_segmentation.sh
- 二分类分割可视化：scripts/plot_binary_segmentation.sh
- 多类分割训练：scripts/multi_segmentation.sh
- 多类分割评估：scripts/eval_multi_segmentation.sh
- 多类分割可视化：scripts/plot_multi_segmentation.sh

==================================================
2. Ubuntu 环境要求
==================================================
建议环境：
- Ubuntu 20.04 / 22.04
- Conda
- Python 3.9
- CUDA 11.3
- NVIDIA 驱动正常

先确认 GPU 可用：

nvidia-smi

==================================================
3. 获取项目
==================================================
cd /your/workspace
git clone https://github.com/yuncheng97/UltraFedFM.git
cd UltraFedFM

如果你当前已经在项目目录，直接执行后续步骤。

==================================================
4. 安装环境
==================================================
项目里有两种方式：

方式 A：直接按 environment.yaml 创建环境
conda env create -f environment.yaml
conda activate ASTR

方式 B：使用项目自带脚本
bash install_env.sh
conda activate ASTR

说明：
- install_env.sh 会创建名为 ASTR 的环境
- 其中默认安装 torch 1.11.0 + cu113
- mmcv-full 单独安装

安装完成后建议检查：
python -V
python -c "import torch; print(torch.__version__); print(torch.cuda.is_available())"

5. 数据准备
==================================================
README 给出的推荐结构如下：

./dataset/
├── toy_pretrain/
│   ├── train/
│   └── 6_clients/
│       └── split_1/
│           ├── client_0.txt
│           ├── client_1.txt
│           └── ...
├── toy_diagnosis/
│   ├── train/
│   │   ├── class0/
│   │   ├── class1/
│   │   └── ...
│   └── test/
│       ├── class0/
│       ├── class1/
│       └── ...
├── toy_segmentation/
│   ├── train/
│   │   ├── image/
│   │   └── mask/
│   └── test/
│       ├── image/
│       └── mask/
└── toy_multi_segmentation/
    ├── train/
    │   ├── image/
    │   └── mask/
    └── test/
        ├── image/
        └── mask/

说明：
- 预训练数据由 train 图像目录 + 客户端划分文本共同组成
- client_x.txt 中每一行存一个图像路径
- 代码会从 ./dataset/${DATASET}/6_clients/split_1/ 这类目录读取客户端划分
- 分类任务使用 torchvision ImageFolder 读取 train/ 和 test/
- 分割任务要求 image/ 与 mask/ 文件名一一对应

README 中提供了 toy dataset 和 checkpoint 下载链接，可直接先用 toy 数据跑通流程。

6. 运行顺序总览
==================================================
推荐按下面顺序执行：

Step 1. 安装环境
Step 2. 准备数据目录
Step 3. 跑联邦预训练，得到预训练权重
Step 4. 用预训练权重跑下游任务训练
Step 5. 跑评估或可视化

如果只想快速验证项目，不必先完整预训练，可以直接下载作者提供的 checkpoint，跳到下游训练或评估。

==================================================
7. 联邦预训练流程
==================================================
默认脚本：

bash scripts/pretrain.sh

该脚本实际会执行类似命令：

CUDA_VISIBLE_DEVICES='0,1,2,3' OMP_NUM_THREADS=1 python -m torch.distributed.launch \
  --nproc_per_node=4 --use_env main_pretrain.py \
  --data_path ./dataset/toy_pretrain/ \
  --data_set toy_pretrain \
  --output_dir ./output_dir/ultrafedfm/pretrained_epoch300_split_1_blr1.5e-4_bs16_ratio0.75_dis4 \
  --blr 1.5e-4 \
  --batch_size 16 \
  --save_ckpt_freq 10 \
  --max_communication_rounds 300 \
  --epochs 300 \
  --split_type split_1 \
  --mask_ratio 0.75 \
  --model mae_vit_base_patch16 \
  --warmup_epochs 40 \
  --weight_decay 0.05 \
  --norm_pix_loss --sync_bn \
  --n_clients 6 --E_epoch 1 --num_local_clients -1

你通常需要改这几个参数：
- DATASET
- DATA_PATH
- SPLIT_TYPE
- N_CLIENTS
- N_GPUS
- CUDA_VISIBLE_DEVICES
- OUTPUT_PATH

预训练输出：
- 日志目录：output_dir/.../log_xxx/
- 周期性 checkpoint
- log.txt / log_file.txt
- tensorboard 日志

训练日志查看：
ls output_dir

TensorBoard：
tensorboard --logdir output_dir --port 6006

==================================================
8. 分类诊断任务
==================================================
8.1 训练
默认脚本：

bash scripts/diagnosis.sh

等价命令：

CUDA_VISIBLE_DEVICES=1 python main_diagnosis.py \
  --model vit_base_patch16 \
  --note toy_diagnosis/vit_b_ssl_usffm \
  --batch_size 32 \
  --epochs 2 \
  --nb_classes 8 \
  --data_path ./dataset/toy_diagnosis \
  --finetune ./output_dir/pretrained_ultrafedfm/log_xxx/checkpoint.pth

你需要修改：
- --data_path
- --nb_classes
- --finetune
- --epochs
- CUDA_VISIBLE_DEVICES

输出内容：
- checkpoint-best_acc.pth
- checkpoint-best_auroc.pth
- runs/ tensorboard 日志
- logging.log

8.2 评估
默认脚本：

bash scripts/eval_diagnosis.sh

等价命令：

CUDA_VISIBLE_DEVICES=1 python main_diagnosis.py \
  --model vit_base_patch16 \
  --batch_size 32 \
  --nb_classes 8 \
  --data_path ./dataset/toy_diagnosis \
  --resume ./output_dir/toy_diagnosis/vit_b_ssl_usffm/log_xxx/checkpoint-best_acc.pth \
  --eval

评估输出通常包括：
- roc.csv
- overall_stat.csv
- confusion_matrix.jpg
- eval 目录下日志

9. 二分类分割任务
==================================================
9.1 训练
默认脚本：

bash scripts/binary_segmentation.sh

等价命令：

CUDA_VISIBLE_DEVICES=1 python main_binary_segmentation.py \
  --datapath ./dataset/toy_segmentation/ \
  --savepath ./output_dir/toy_segmentation \
  --batch_size 96 \
  --epoch 128 \
  --note vit_b_ssl_usffm \
  --pretrained ./output_dir/pretrained_ultrafedfm/log_xxx/checkpoint.pth

你需要修改：
- --datapath
- --pretrained
- --batch_size
- --epoch
- CUDA_VISIBLE_DEVICES

训练输出：
- epoch_bestDice.pth
- log.log
- TensorBoard 日志

9.2 评估
默认脚本：

bash scripts/eval_binary_segmentation.sh

等价命令：

CUDA_VISIBLE_DEVICES=0 python main_binary_segmentation.py \
  --datapath ./dataset/toy_segmentation/ \
  --savepath ./output_dir/toy_segmentation \
  --batch_size 32 \
  --note vit_b_ssl_usffm \
  --resume ./output_dir/toy_segmentation/vit_b_ssl_usffm/log_xxx/epoch_bestDice.pth \
  --eval

9.3 结果可视化
默认脚本：

bash scripts/plot_binary_segmentation.sh

会把预测结果保存到类似目录：
- output_dir/.../figures/

11. 最短跑通路径
==================================================
如果只是先验证代码能跑，建议用 toy 数据按下面顺序：

(1) conda env create -f environment.yaml
(2) conda activate ASTR
(3) 准备 ./dataset/toy_pretrain、./dataset/toy_diagnosis、./dataset/toy_segmentation、./dataset/toy_multi_segmentation
(4) bash scripts/pretrain.sh
(5) 修改 scripts/diagnosis.sh 中 --finetune 指向你的预训练 checkpoint
(6) bash scripts/diagnosis.sh
(7) bash scripts/eval_diagnosis.sh
(8) bash scripts/binary_segmentation.sh
(9) bash scripts/eval_binary_segmentation.sh
(10) bash scripts/multi_segmentation.sh
(11) bash scripts/eval_multi_segmentation.sh

如果不想等待预训练：
- 先下载作者提供的 checkpoint
- 把脚本里的 --finetune 或 --pretrained 改成该 checkpoint
- 直接从分类/分割训练开始

==================================================
14. 输出目录规律
==================================================
项目多数训练任务都会在 output_dir 下自动新建时间戳目录，例如：

output_dir/toy_diagnosis/vit_b_ssl_usffm/log_2026-04-28_12:00:00/

这里通常会包含：
- checkpoint-best_acc.pth 或 checkpoint-best_auroc.pth
- epoch_bestDice.pth
- logging.log / log.log
- runs/
- eval/
- figures/ 或 figures_multi/

==================================================
15. 推荐执行顺序
==================================================
最佳运行顺序只有一条：

先装环境 -> 准备数据 -> 预训练 -> 下游训练 -> 下游评估/可视化

如果你只做复现验证：

先装环境 -> 下载作者 checkpoint -> 直接做下游训练或评估
